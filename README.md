# DRILL44 AI

DRILL44 AI — локальный веб‑сайт с премиальным интерфейсом (dark + glassmorphism) для генерации промптов и тестирования image‑pipeline в 3 режимах:

1. **Редактор сцены**
2. **Face Swap (NanoBanana)**
3. **Карусель вариаций**

## Главное: работает сразу

Если у вас **нет ключа NanoBanana**, приложение автоматически использует **DEMO Image Provider**:
- сервер локально создает реальные PNG изображения;
- отображаются превью, работает скачивание и ZIP;
- jobs/polling работают как в боевом режиме.

Когда появится ключ NanoBanana — достаточно вставить его в настройки, фронтенд менять не нужно.

## Стек

- Фронтенд: `index.html`, `styles.css`, `app.js` (чистый Vanilla JS)
- Бэкенд: `server/` (`Node.js + Express`)

## Установка и запуск

```bash
npm install
npm run start
```

Откройте: `http://localhost:4177` (или порт из переменной `PORT`).

## Хранение ключей и файлов

Секреты и временные файлы хранятся только на сервере в macOS:

- `~/Library/Application Support/DRILL44 AI/settings.json`
- `~/Library/Application Support/DRILL44 AI/tmp/`

Безопасность:
- ключи не сохраняются в браузере;
- ключи не пишутся в localStorage;
- `GET /api/settings` возвращает только `hasKey` и публичные поля.

## Prompt providers (работают сразу)

Поддержаны:
- OpenAI (ChatGPT)
- xAI (Grok)

В настройках для каждого провайдера доступны:
- `baseUrl`
- `model`
- `endpointPath`
- `apiKey`

Форматы генерации:
- **Classic** (текст)
- **JSON**

## Image providers

### 1) DEMO (автоматически при отсутствии NanoBanana API key)

Генерирует PNG локально с:
- названием DRILL44 AI,
- режимом,
- номером варианта,
- временем,
- digest по промпту.

### 2) NanoBanana

Настраивается в панели справа:
- `baseUrl`
- `apiKey`
- `model` (`pro` или `v2`)
- `scenePath`, `faceSwapPath`, `carouselPath`

## Режимы

### Редактор сцены
- Лицо (обязательно), Комната (опционально), Одежда/аксессуар (опционально)
- Промпт опционально
- Кнопки: **Сгенерировать промпт**, **Сгенерировать сцену**
- Результат: превью, метаданные, скачать, копировать промпт, повторить

### Face Swap (NanoBanana)
- Референс лица обязателен
- Фигура и стиль опциональны
- Обязательный чекбокс подтверждения прав на изображения
- Результат в том же формате, что у редактора сцены

### Карусель вариаций
- Референс фото обязателен
- Промпт опционален (пусто = smart variation)
- Количество: `2/3/4/6/8`
- Результат: карусель + миниатюры + режим сетки + стрелки клавиатуры + ZIP

## API

- `GET /api/settings`
- `POST /api/settings`
- `POST /api/providers/test`
- `POST /api/prompts/generate`
- `POST /api/jobs/scene`
- `POST /api/jobs/faceswap`
- `POST /api/jobs/carousel`
- `GET /api/jobs/:id`
- `POST /api/jobs/:id/cancel`
- `GET /api/files/:fileId`
- `GET /api/jobs/:id/zip`

## Очистка tmp

Файлы в `tmp` удаляются:
- при старте сервера,
- затем периодически (раз в час),
- если старше 24 часов.

## Как проверить OpenAI/Grok

1. Откройте настройки.
2. Введите ключи OpenAI/xAI и нажмите **Сохранить**.
3. Нажмите **Проверить**.
4. В любом режиме нажмите **Сгенерировать промпт**.

## Как включить NanoBanana позже

1. Откройте настройки справа.
2. Вставьте NanoBanana `apiKey` и проверьте `baseUrl/paths/model`.
3. Нажмите **Сохранить**.
4. Бейдж в сайдбаре переключится с `Image: DEMO` на `Image: NanoBanana`.

## Тестовый сценарий

1. `npm install`
2. `npm run start`
3. Открыть `http://localhost:4177`
4. В настройках добавить ключ OpenAI или xAI, сохранить и проверить
5. В Карусели: загрузить фото, выбрать 4 варианта, сгенерировать, скачать ZIP
6. В Редакторе сцены: загрузить лицо (и при желании комнату), оставить промпт пустым, сгенерировать
7. В Face Swap: загрузить лицо+фигуру, включить чекбокс, сгенерировать
