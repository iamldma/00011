# DRILL44 AI

DRILL44 AI — локальный веб‑сайт (не расширение) с премиальным тёмным интерфейсом для работы с NanoBanana в трёх режимах:
- **Редактор сцены**
- **Face Swap (NanoBanana)**
- **Карусель вариаций**

Также поддерживается генерация промптов через LLM‑провайдеры в форматах **Classic** (текст) и **JSON**.

## Установка и запуск

1. Установите Node.js LTS (рекомендуется 18+).
2. В корне проекта выполните:
   ```bash
   npm install
   npm run start
   ```
3. Откройте в браузере: `http://localhost:4177` (или порт из переменной `PORT`).

## Где хранятся настройки и временные файлы

Сервер хранит чувствительные данные только на стороне сервера в macOS:
- `~/Library/Application Support/DRILL44 AI/settings.json`
- `~/Library/Application Support/DRILL44 AI/tmp/`

Ключи **не сохраняются в браузере**, **не пишутся в localStorage**, **не отдаются в `/api/settings`**.

## Подключение ключей

1. Откройте панель **Настройки** справа.
2. Для LLM провайдеров укажите `Base URL`, `Модель`, `API Key`.
3. Для NanoBanana укажите `Base URL`, `API Key`, пути `scenePath`, `faceSwapPath`, `carouselPath`.
4. Нажмите **Сохранить**.
5. Нажмите **Проверить LLM** и/или **Проверить NanoBanana**.

### Показ/скрытие ключей

Поле ключей замаскировано по умолчанию. Для временного просмотра включите чекбокс **Показать ключи**.

## Выбор NanoBanana Pro / NanoBanana 2

В настройках NanoBanana есть селектор модели:
- `pro` → NanoBanana Pro
- `v2` → NanoBanana 2

Выбранная модель автоматически уходит в запросы `/api/jobs/scene`, `/api/jobs/faceswap`, `/api/jobs/carousel`.

## Формат промптов: Classic / JSON

В правой панели выберите формат:
- **Текстовый (Classic)** — обычный текстовый промпт.
- **JSON** — структурированный JSON‑промпт.

Кнопка **Сгенерировать промпт** в каждом режиме вызывает `/api/prompts/generate`, затем полученный текст/JSON вставляется в поле промпта.

## Как скачать ZIP в карусели

После завершения режима **Карусель вариаций** нажмите **Скачать всё ZIP**.
Сервер соберёт архив из файлов задачи через `GET /api/jobs/:id/zip`.

## Очистка tmp

Временные файлы из `tmp` очищаются:
- при старте сервера;
- далее периодически (раз в час);
- удаляются файлы старше 24 часов.

## API

- `GET  /api/settings`
- `POST /api/settings`
- `POST /api/providers/test`
- `POST /api/prompts/generate`
- `POST /api/jobs/scene`
- `POST /api/jobs/faceswap`
- `POST /api/jobs/carousel`
- `GET  /api/jobs/:id`
- `GET  /api/files/:fileId`
- `GET  /api/jobs/:id/zip`

## Тестовый сценарий

1. `npm install`
2. `npm run start`
3. открыть `http://localhost:PORT`
4. зайти в **Настройки** -> вставить ключи -> **Сохранить** -> **Проверить подключение**
5. зайти в **Карусель** -> загрузить фото -> 4 варианта -> сгенерировать -> скачать ZIP
6. зайти в **Редактор сцены** -> загрузить лицо + комнату -> промпт пустой -> сгенерировать
7. зайти в **Face Swap** -> загрузить лицо + фигуру -> включить чекбокс подтверждения -> сгенерировать
